# # The Wing's House — Burger · Ribs · Beer 🍗🍔🍺

Sitio web web oficial MVP para el bar y restaurante **The Wing's House**.

> ⚠️ **REGLA DE ORO**: Este proyecto utiliza **exclusivamente fotografías reales** tomadas directamente en el establecimiento y de sus productos oficiales. No se utiliza ninguna imagen generada por IA.

---

## 🚀 Características

- **Diseño Gastronómico Premium**: Estética industrial nocturna con luces cálidas tipo Edison, elementos glassmorphicos y detalles temáticos.
- **Galería de Fotografías Reales**: Visor modal de las 5 fotos oficiales del local y platillos.
- **Carta & Menú Interactivo**:
  - Filtros por categorías (`Todo`, `📸 Solo Fotos Reales`, `Alitas`, `Hamburguesas`, `Costillas BBQ`, `Acompañamientos`, `Cervezas & Vinos`).
  - Buscador de platos en tiempo real.
  - Personalizador de salsas por producto.
  - Tarjetas tipográficas elegantes para platillos sin fotografía.
- **Integración Directa con WhatsApp**:
  - Carrito de compras desplegable.
  - Generador de mensaje formateado con dirección de envío/mesa y cálculo total.
- **Ubicación & Enlaces**:
  - Acceso directo a Google Maps y página de Facebook.

---

## 🛠️ Tecnologías

- **React 18 + TypeScript**
- **Vite 6**
- **Tailwind CSS / Vanilla CSS Design Tokens**
- **Lucide React** (Iconografía)
- **Canvas Confetti**

---

## 💻 Desarrollo Local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Olarte1046/thewingshousebar.git
   cd thewingshousebar
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Compilar para producción:
   ```bash
   npm run build
   ```

---

## 🌐 Despliegue en Vercel

Este proyecto está optimizado para desplegarse automáticamente en Vercel:
1. Conecta este repositorio en [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
